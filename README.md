# Ἀγορά (Agora)

Agora는 Claude Code, Codex CLI, Antigravity(`agy`)를 한 화면에서 사용하는 Windows 데스크톱 앱입니다.

간단한 질문은 한 AI에게 바로 물어보고, 여러 의견이 필요할 때는 `@모두`로 함께 묻거나 AI끼리 토론하게 할 수 있습니다. 프로젝트 폴더를 연결하면 사용자가 허용한 범위에서 AI가 파일을 읽거나 수정하는 작업도 맡길 수 있습니다.

팀에 처음 공유할 때는 아래 설치·사용 안내부터 읽으면 됩니다. 구현 범위와 검증 상태, 과거 설계 문서의 구분은 [문서 안내](docs/README.md)에 모았습니다.

## 처음 시작하기

| 처음 설치한다면 | 설치를 마쳤다면 |
|---|---|
| **[설치 가이드](설치-가이드.md)** — Windows 설치와 AI 계정 연결 | **[사용 안내](사용-안내.md)** — 첫 프로젝트 만들기, 일반 대화, 토론, 프로젝트 기록 |

Windows에서는 저장소 폴더의 **`Agora-설치하기.bat`**를 실행하면 필요한 프로그램을 확인하고 설치를 안내합니다. 이후 업데이트는 **`Agora-업데이트.bat`**로 진행할 수 있습니다.

ZIP으로 내려받은 폴더는 자동 업데이트되지 않습니다. 새 ZIP으로 교체하거나 [GitHub Releases](https://github.com/Eachelp/Agora/releases)에서 단독 실행 파일을 받으세요.

## 주요 기능

- **여러 AI와 한 화면에서 대화:** `@claude`, `@gpt`, `@gemini`처럼 대상을 지정하거나 `@모두`로 연결된 AI 전체에 질문할 수 있습니다.

- **AI 간 토론:** 여러 AI가 앞선 의견을 검토하고 정해진 라운드 동안 토론합니다. 서로 다른 관점을 비교하거나 쟁점을 정리할 때 유용합니다.

- **프로젝트별 폴더와 권한 관리:** 프로젝트마다 작업 폴더와 공통 규칙을 연결하고, 파일 접근 범위를 대화만·읽기·쓰기로 나눠 설정합니다.

- **프로젝트 기록:** 프로젝트별 메모리·결정·작업 기록과 공통 규칙을 남기면 이후 대화에 함께 전달됩니다. 끝난 토론은 자동으로 기록됩니다.

- **다른 AI에게 전달:** 한 AI의 답변을 다른 AI에게 넘겨 검토받거나 다음 작업을 이어갈 수 있습니다.

- **마크다운과 파일 첨부:** 이미지와 파일을 첨부할 수 있으며 코드 블록, 표, 수식(LaTeX)을 표시합니다.

## 지원 환경

Agora는 Windows를 기본 지원하는 로컬 데스크톱 앱입니다.

- **공식 지원:** Windows
- **참고 지원:** Linux(AppImage)
- **실험적 지원:** macOS

> **Antigravity IDE와 `agy` CLI는 별개입니다.** Agora에서 Gemini를 사용하려면 `agy` CLI를 따로 설치하고 로그인해야 합니다.

## 워크스페이스 권한

Agora의 파일 접근 권한은 세 단계로 나뉩니다.

| 권한 | 가능한 작업 |
|---|---|
| **대화만** | 파일을 읽거나 수정하지 않고 대화만 합니다. |
| **워크스페이스 읽기** | 연결한 프로젝트 폴더의 파일을 읽고 검색합니다. |
| **워크스페이스 쓰기** | 연결한 폴더의 파일을 만들거나 수정하고 명령을 실행할 수 있습니다. |

도구 자동 승인은 워크스페이스 쓰기 모드에서만 켤 수 있습니다. 출처와 내용을 알고 있는 프로젝트 폴더에서만 사용하세요.

## 모델 목록 갱신

모델 목록은 설치된 CLI와 계정에서 확인할 수 있는 범위로 갱신합니다. 앱을 켜 둔 동안 CLI 버전·로그인을 1시간마다 다시 확인하고, 모델 목록은 6시간의 캐시 유효기간이나 CLI 변경에 따라 다시 조회합니다. 채팅 창 왼쪽 아래 **환경 진단** 줄 끝의 새로고침 아이콘(**CLI 다시 탐지**)으로 즉시 재조회할 수도 있습니다.

- Codex와 AGY는 CLI가 제공하는 모델 목록에서 새 항목을 가져옵니다.
- Claude는 CLI 도움말이 제공하는 모델 별칭을 갱신합니다. 모든 고정 버전 모델을 자동으로 나열하는 방식은 아닙니다.
- 갱신 후에는 열려 있던 모델 선택창을 닫았다가 다시 여세요. 조회에 실패하면 기존 목록을 유지합니다.

## 데이터 저장과 AI 서비스 연결

Agora가 관리하는 설정, 대화 기록, 첨부 파일과 실행 로그는 기본적으로 다음 경로에 저장됩니다.

```text
%USERPROFILE%\.agora\
```

환경 변수 `AGORA_HOME`을 설정하면 저장 위치를 바꿀 수 있습니다.

```text
.agora/
├─ config.json                         앱 설정과 CLI 탐지 정보
└─ sessions/<id>/
   ├─ meta.json                        세션, 프로젝트, 권한, 에이전트 설정
   ├─ transcript.jsonl                 대화 기록
   ├─ attachments/                     첨부 파일
   └─ run-logs/                        실행 로그
```

- Agora는 AI 서비스의 비밀번호를 직접 입력받지 않습니다. 계정 전환 기능을 사용하면 각 CLI가 발급한 로그인 인증정보 사본을 이 PC에 저장합니다. 저장된 정보는 계정 전환과 사용량 확인에 사용되므로 로그인 비밀번호와 같은 수준으로 보호해야 합니다.
- 질문과 작업 내용은 사용자가 선택한 Claude, Codex, AGY의 공식 CLI를 거쳐 해당 AI 서비스로 전달됩니다.
- 프로젝트 파일은 사용자가 지정한 워크스페이스와 권한 범위 안에서 읽거나 수정합니다.

## 개발 및 직접 실행

개발자가 소스에서 직접 실행하려면 Node.js와 npm이 필요합니다.

```powershell
npm install
npm start
```

테스트:

```powershell
npm test
```

Windows 단독 실행 파일 빌드:

```powershell
npm run dist -- --win
```

빌드 결과:

```text
artifacts/Agora-<버전>.exe
```
