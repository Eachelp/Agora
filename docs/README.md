## 현재 지원 범위

| 기능 | 현재 동작 |
|---|---|
| 일반 대화 | `@claude`·`@gpt`·`@gemini`, `@모두` 이어 발언·독립 발언 |
| 바로 답하기 | 여러 AI가 답하는 중에 한 AI를 이름으로 불러 답장하면 다른 AI를 기다리지 않고 바로 답함(그 AI가 아직 앞선 답을 하는 중이면 끝나자마자). 이어 발언·`@모두`·토론은 순서대로 ([설계·개정 기록](design/AGORA_REVISION_2026-10-11_REPLY_NOW.md)) |
| 오케스트레이터 | 방 머리줄의 **[오케스트레이터]** 칩으로 켜고 지휘 AI를 고름(방마다 기억). 켜지면 @ 없는 메시지는 지휘 AI에게 가고, 지휘 AI가 `STAGE` 줄로 일을 단계로 나눠 맡기면 같은 단계는 함께 시작하고 단계 사이는 차례로 실행하며(다음 단계가 앞 단계 결과를 받음) 마지막 단계가 끝나면 지휘 AI에게 한 번에 모여 돌아옴. 지휘 AI가 다음 단계·완료를 표시하지 않으면 한 번 재촉. 지휘 모델·노력과 읽기 전용을 따로 정할 수 있음. @로 부른 메시지는 모드와 무관하게 항상 그 AI에게 바로 감. 입력창 위 **"AI끼리 계속 부르기"** 체크(기본 꺼짐)는 보통 대화의 @멘션 연쇄 상한(기본 2)을 풀며, 오케스트레이터의 지휘 AI·작업자 호출에는 적용되지 않음 ([설계·개정 기록](design/AGORA_REVISION_2026-10-11_ORCHESTRATOR.md), [2026-10-20 개정](design/AGORA_REVISION_2026-10-20_ORCHESTRATOR_STAGES.md)) |
| 토론 | 발언 수를 정하는 자유토론, Preset과 사이클에 따른 구조화 토론 |
| 실행 중 질문 카드 | Claude·Codex가 일하다 던지는 질문(1~4개, 하나 고르기·여러 개 고르기·직접 입력)에 카드로 답하면 같은 작업이 이어짐. 건너뛰기·중지로 닫을 수 있음. 파일 작업(읽기·쓰기) 권한의 일반 대화에서만 붙고, 대화 전용·AGY·토론에는 없음(대화 전용은 답변 끝에서 선택지로 묻는다) ([개정 기록](design/AGORA_REVISION_2026-10-11_QUESTION_UI.md)) |
| 답변 대기·승인 | AI가 응답을 끝내며 되묻는 질문에 답하면 이어 진행, 권한 밖 작업은 "도구 실행 권한 요청" 창에서 확인. 폴더를 청한 요청은 **[이 폴더만 열고 다시 실행]**, 좁힐 수 없는 요청은 경고와 함께 **[모든 제한을 풀고 다시 실행]**, 또는 **[거부]**. 요청은 대화별로 보이고 창을 다시 열어도 남음 |
| 중지·잠깐·대기 취소 | 응답 중이거나 승인을 기다리는 대화에서 **[중지]**(전부 멈춤), **[잠깐]**(멈추고 발언권을 사용자에게), 대기 발언의 **×**(그 발언만 취소) |
| 동시 대화 | 한 프로젝트 폴더에서 두 대화가 동시에 일할 수 있음. 같은 파일을 동시에 고치면 나중에 저장한 쪽이 남음 |
| 프로젝트 기록 | 프로젝트별 메모리·결정·작업 기록과 규칙을 대화에 전달. 끝난 토론은 프로젝트 설정의 "토론 자동 기록"에서 기록 담당을 고른 프로젝트에서만 자동 기록 |
| AnchorMind 기억(선택) | 따로 설치한 AnchorMind 6.7.1을 설정의 **기억 애드온**에서 폴더로 연결하고 프로젝트마다 켬(기본 꺼짐, 미분류 제외). 켠 프로젝트에서는 사용자 메시지마다 관련 기억만 골라 프롬프트에 넣음(최대 3초 기다리고, 실패하면 기억 없이 진행). **[기억하기]**·확정한 결정·토론 기록 요약, 그리고 AI가 답 끝에 직접 고른 기억(오케스트레이터 작업자는 제외, 그 줄은 화면에서 숨김)을 저장하고 **[프로젝트 기록]**의 AnchorMind 탭에서 보기·고치기·지우기(최신 100개). 켜기·끄기 명령을 둘 다 넣으면 Agora가 켜고, Agora가 켠 AnchorMind만 30분 유휴·앱 종료 때 끔. 보내는 메시지의 앞 1,000자와 저장하는 기억(AI가 고른 것 포함)은 Google Gemini API로 감 ([설계안](design/AGORA_PROPOSAL_2026-10-23_ANCHORMIND_ADDON.md), [실행 계획](design/AGORA_PLAN_2026-10-23_ANCHORMIND_ADDON.md)) |
| 모델 목록 | CLI 버전·로그인 1시간 재확인, 모델 목록 캐시 6시간. Codex·AGY 목록과 Claude 도움말 별칭 갱신 |

전문 모드·역할 상담·`@팀 실행`은 제거되었고, 그 자리는 일반 대화 안의 오케스트레이터 모드로 대체되었습니다. 모델 자동 갱신은 CLI와 계정이 제공하는 목록에 한정되며, 모든 신모델의 실시간 발견을 보장하지 않습니다. 갱신 후 열려 있던 모델 선택창은 다시 열어야 합니다.

## 팀 확인과 검증 기록
